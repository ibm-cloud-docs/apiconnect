# Federated API Management in {{site.data.keyword.apiconnect_short}} V12 Reserved
{: #v12ri-fed-api-mgmt}

Federated API Management provides a unified way to manage, govern, and monitor multiple distributed API runtimes and data planes from a single interface, regardless of where they are deployed.
{: shortdesc}

## Overview
{: #overview_v12ri-fed-api-mgmt}

Federated API Management enables organizations to centrally monitor and manage various runtimes such as:
- webMethods API Gateway
- DataPower Gateway
- DataPower Nano Gateway
- IBM Developer Portal
- IBM API Connect CMS portal
- External runtimes such as AWS API Gateway, Azure API Management Service, and third-party gateways via SDK integration

Federated API Management provides the following key benefits:

- **Unified policy templates** — Create and enforce consistent governance policies across all connected API environments.
- **Cross-platform visibility** — Monitor performance, security, compliance, and subscription management across all connected runtimes from a single dashboard.
- **Centralized runtime management** — Add, configure, and monitor gateway and portal runtimes from one place without switching between different administrative interfaces.
- **Distributed API operations** — Manage API runtimes across different regions, cloud platforms, or vendors as a single unified system.

## Getting started
{: #getting_started_v12ri-fed-api-mgmt}

To use Federated API Management in your V12 Reserved instance:

1. Log in to your V12 Reserved administration console.
2. Navigate to **Federated API Management** in the main navigation.
3. Connect your first API runtime by following the getting started guide.

For complete instructions on setting up and using Federated API Management, see the [Federated API Management documentation](https://www.ibm.com/docs/en/api-connect/saas){: external}.

## Managing runtimes
{: #runtimes_v12ri-fed-api-mgmt}

Federated API Management enables you to:
- Add and register API gateway runtimes
- Configure data planes for distributed deployments
- Monitor the health and status of all connected runtimes
- Apply policy templates consistently across environments

## APIs
{: #apis_v12ri-fed-api-mgmt}

Use the Federated API Management interface to view and manage APIs across all connected runtimes. You can:
- View all published APIs across connected runtimes
- Manage API keys
- Monitor API usage and performance

## Administration APIs
{: #admin_apis_v12ri-fed-api-mgmt}

Federated API Management exposes REST APIs for programmatic administration. For the complete API reference, see the [administration API documentation](https://www.ibm.com/docs/en/api-connect/saas){: external}.

## Monitoring
{: #monitoring_v12ri-fed-api-mgmt}

Federated API Management provides monitoring dashboards that give you visibility into the health and performance of all connected API runtimes. For information on monitoring your federated environment, see the [complete V12 Reserved documentation](https://www.ibm.com/docs/en/api-connect/saas){: external}.
