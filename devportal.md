# Using the IBM Developer Portal in {{site.data.keyword.apiconnect_short}} V12 Reserved
{: #v12ridevportal}

The IBM Developer Portal is a web-based, self-service portal that enables your organization to securely expose APIs to external developers, partners, and other consumers. V12 Reserved includes the new IBM Developer Portal (in addition to the classic API Connect Developer Portal).
{: shortdesc}

## Overview
{: #overview_v12ri-devportal}

The IBM Developer Portal supports three key user groups:

- **API Providers** — Publish and monetize APIs, organize hackathon programs, and track performance and usage with built-in analytics dashboards.
- **API Consumers** — Discover, test, and subscribe to APIs, obtain code samples, and collaborate with the development community.
- **Administrators** — Configure portal settings and features, oversee user communities, and set up marketplaces for multiple provider and consumer organizations.

## Configuring the IBM Developer Portal
{: #configure_v12ri-devportal}

To configure the IBM Developer Portal for your V12 Reserved instance:

1. Log in to your V12 Reserved administration console.
2. Navigate to the **Developer Portal** section.
3. Create and configure your portal instance.

For detailed configuration instructions, see the [IBM Developer Portal documentation](https://www.ibm.com/docs/en/api-connect/saas){: external}.

## Managing APIs through the portal
{: #manage_apis_v12ri-devportal}

After configuring the portal, API providers can:
- Publish API products and make them available to consumers
- Set up hackathon programs and engagement initiatives
- Monitor API usage through the built-in analytics dashboards

## Consumer experience
{: #consumer_v12ri-devportal}

Application developers who consume APIs through the Developer Portal can:
- Browse the API catalog and discover available APIs
- View API documentation and test APIs interactively
- Subscribe to API plans and manage their subscriptions
- Collaborate with the community through comments and discussions

## Classic Developer Portal
{: #classic_portal_v12ri-devportal}

V12 Reserved also includes the classic API Connect Developer Portal. For information on using the classic portal, see [Socializing your APIs with a Developer Portal](/docs/apiconnect?topic=apiconnect-ri-devportal) in the V10 Reserved documentation. Both portals are available in V12 Reserved.
